# Security Policy

Better San Fernando is an independent public information site. Please report vulnerabilities that could affect the site, its users, or its data handling responsibly.

## Reporting a vulnerability

Do not post exploit details, personal data, credentials, or an active vulnerability in a public issue or discussion. Use GitHub's private vulnerability reporting for this repository when available. If it is unavailable, contact the repository maintainers privately through GitHub and ask for a secure reporting channel.

Include the affected route or component, steps to reproduce, potential impact, and any suggested mitigation. Do not access, alter, or retain data beyond what is necessary to demonstrate the issue.

Maintainers will acknowledge reports as soon as practical, investigate, and coordinate any fix or disclosure with the reporter. Please allow time for a fix before public disclosure.
